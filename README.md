CrimeVision AI

Multimodal forensic analysis platform. It analyzes image, video and audio evidence, builds one chronological timeline, and generates a forensic PDF report. An AI chat lets investigators ask questions about the evidence.

Demo video: https://youtu.be/pxeF8mtGWFA

Features Object, person and weapon detection (RT-DETR) in images and video frames Scene classification (CLIP) and scene descriptions (BLIP) Multilingual audio transcription with timestamps (Whisper) Unified timeline that fuses image, video and audio findings Crime classification, scenario reasoning and evidence chat (Groq LLM) Flask dashboard with REST API, 3D timeline view and PDF reports SHA-256 hash recorded for every uploaded evidence file
